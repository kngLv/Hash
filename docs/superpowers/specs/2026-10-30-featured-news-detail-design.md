# 精选新闻详情页设计说明

## 目标

为精选新闻列表增加原生详情页。用户点击任一新闻后，在应用内查看标题、来源、发布时间和正文；不跳转外部浏览器或新闻网站，并保持现有浅色/深色主题与请求状态规范。

## 接口与数据

- 使用 MXNZP “每日最新新闻” V2 详情接口：`GET /api/news/details/v2`。
- 请求参数沿用现有新闻列表认证参数，并传入列表项的 `newsId`。
- 新增详情响应模型，字段均按接口 JSON 名称用 `@field:SerializedName` 显式映射；正文、图片和视频等非稳定字段使用可空类型，避免单条新闻字段缺失导致整个页面解析失败。
- 详情 Repository 沿用现有 `request { }.onError { }.execute()` 请求约定，不新增另一套网络调用方式。

## 页面与交互

- 新增 `NewsDetailActivity`，通过 ARouter 接收 `newsId`，列表点击时跳转。
- 顶部为返回按钮；内容区按“标题 → 来源/发布时间 → 正文”展示。
- 正文按原生文本排版呈现。接口正文若包含 HTML 标记，会转换为可读富文本；不嵌入新闻网站页面。
- 详情数据中的图片按原顺序使用现有 `ImageLoader` 展示；无图片时不保留空白区域。
- 页面首次加载使用现有 Activity 级 Loading；失败时显示错误提示并保留返回能力；空正文显示明确的空状态。

## 非目标

- 不实现评论、点赞、收藏、分享和相关推荐。
- 不实现离线详情缓存，也不更改精选列表现有缓存策略。
- 不使用 WebView，不加载新闻原网站。

## 验证

- 为详情模型解析和正文转换逻辑补充单元测试：完整字段、缺省媒体字段和 HTML 正文三种情况。
- 编译 `feature:home` 的 release 资源与 Kotlin；若全链路构建仍受本机 JDK 17 与项目 Java 21 配置冲突影响，明确记录该环境阻塞。
- 手工验证：列表点击跳转、返回、深色模式、加载失败、无正文及含图片新闻。
